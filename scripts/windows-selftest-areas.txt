# The Windows app self-test's areas (apps/windows/NvrView.App/SelfTest*.cs).
#
# `NvrView.App.exe --selftest N ... --areas a,b` runs only those areas (plus
# "startup", which always runs); scripts/suite-cache.py caches each area on
# its own. Every `// parity: <id>` step belongs to exactly one area, found
# here by the longest matching pattern: `area  id` (exact) or `area  prefix*`.
# scripts/check-selftest-areas.py fails when a step matches no pattern, a
# pattern matches no step, or two patterns of different areas tie.
#
# Which code runs for an area is decided in the self-test source (Runs and
# RunsAny in SelfTest.cs; the area list there is AreaNames). Which files
# invalidate an area is decided in scripts/suite-cache.py (WINDOWS_OWNED).
