# The macOS app self-test's areas (apps/macos/Sources/NVRView/SelfTest.swift).
#
# `NVRView --fake ... --selftest N --areas a,b` runs only those areas (plus
# "startup", which always runs); scripts/suite-cache.py caches each area on
# its own (mac-app.AREA). Every `// parity: <id>` step belongs to exactly one
# area, found here by the longest matching pattern: `area  id` (exact) or
# `area  prefix*`. scripts/check-selftest-areas.py fails when a step matches
# no pattern, a pattern matches no step, or two patterns of different areas
# tie. The names follow the Windows areas (scripts/windows-selftest-areas.txt)
# where the steps correspond; a step sits where the Mac self-test's chain runs
# it, which is not always the Windows area.
#
# Which code runs for an area is decided in the self-test source (runs(...) in
# SelfTest.swift; the area list there is areaNames). Which files invalidate an
# area is decided in scripts/suite-cache.py (MAC_OWNED).
